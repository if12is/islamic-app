# النشر على Uptodown

## أولاً: الحقيقة التي يبني عليها كل ما تحت

**Uptodown ليس لها واجهة برمجية عامة للنشر.** كونسول المطوّرين موقع ويب فقط: لا
مفاتيح API، ولا نقاط رفع، ولا شيء يستطيع GitHub Actions مناداته. بحثت في توثيقهم
وفي مركز مساعدتهم وفي صفحة الكونسول نفسها ولم أجد شيئاً.

فالوعد بـ«ورك فلو يرفع أي تحديث تلقائياً» **لا يمكن الوفاء به** — وقول ذلك أفضل من
تسليمك شيئاً يبدو أنه يعمل ثم يصمت.

## ما يمكن فعله، وهو قريب جداً

حوار الرفع عندهم فيه خانة **«Use url»** بدل رفع الملف. ورابط إصدار GitHub **ثابت
ولا يتغيّر ولا يحتاج تسجيل دخول**:

```
https://github.com/if12is/islamic-app/releases/download/apk-latest/islamic-app-latest-arm64-v8a.apk
https://github.com/if12is/islamic-app/releases/download/apk-latest/islamic-app-latest-armeabi-v7a.apk
```

تحققت منهما: يردّان `200` و‏86.8 و‏93.7 ميجابايت بلا أي مصادقة.

فالـworkflow يجهّز لك **كل ما يطلبه النموذج** بعد كل بناء ويضعه في ملخّص التشغيل:
الروابط، ورقم الإصدار، ورقم البناء، والبصمة، والحجم. ويبقى عليك **لصق ونقرتان**.

## إنشاء التطبيق على Uptodown — الخطوات

### ١. الحساب
[en.uptodown.com/developers-console](https://en.uptodown.com/developers-console) ←
**Create an account**. مجاني، بلا رسوم ولا حصّة أرباح ولا SDK إجباري.

### ٢. `ADD NEW APP`

| الحقل | القيمة |
|---|---|
| Operating system | **Android** |
| Select file | فعّل **☑ Use url** والصق رابط `arm64-v8a` أعلاه |

الرابط أفضل من رفع الملف: ٨٦ ميجابايت من جهازك في كل تحديث مقابل لصق سطر.

### ٣. بيانات القائمة

انسخها من `store/listing.md` — الاسم والوصفان القصير والطويل بالعربية والإنجليزية،
والتصنيف والوسوم.

### ٤. الصور

- **الأيقونة**: `icon.png` في جذر المشروع (١٠٢٤×١٠٢٤)
- **لقطات الشاشة**: `ads/cards/*.png` (١٠٨٠×١٩٢٠) — خمس عشرة بطاقة جاهزة
- ابدأ بـ`home` و`prayer_times` و`quran` و`wird` و`reader`

### ٥. إعداد واحد مهم

في تبويب الملفات، فعّل **«Disable uploads by Uptodown editors»** إن أردت أنت وحدك
من يرفع النسخ. محرّرو Uptodown يحدّثون التطبيقات تلقائياً من مصادر أخرى — وتطبيقك
ليس على Google Play، فلن يجدوا شيئاً، لكن الإعداد يمنع أي مفاجأة.

## التحديثات بعد ذلك

في تبويب **Files** ← **+ Add new version** ← **☑ Use url** ← الصق نفس الرابط.

الرابط ثابت، لكن **رقم البناء لا بد أن يكون أعلى من السابق**، وهو كذلك دائماً:
الـworkflow يأخذه من رقم تشغيل GitHub الذي لا ينقص أبداً.

## ثلاث حواجز ستقابلها

**١. حجم الملف.** ٨٦ ميجابايت للمعمارية الواحدة. حدّهم ٨ جيجابايت فلا مشكلة، لكن
الرفع من جهازك بطيء — ولهذا الرابط.

**٢. المعماريتان.** الـworkflow يبني `arm64-v8a` و`armeabi-v7a` منفصلتين. ارفع
`arm64-v8a` أولاً فهي ما يعمل عليه كل هاتف حديث، ثم أضف الثانية كملف بديل.

**٣. التوقيع.** كل بناء يُوقَّع بالمفتاح نفسه من أسرار المستودع، فالتحديثات تُثبَّت
فوق بعضها. لا تغيّره أبداً: تغييره يعني أن أحداً لن يستطيع التحديث دون حذف التطبيق.
