# Interactive Prototype Map & User Flow Document **App Name:** Al-Fajr (Islamic Companion) **Target Framework:** Flutter (Material 3) **Primary Layout:** RTL (Right-to-Left) **Font:** Cairo (Global) --- ## 1. Global Navigation & Routing Logic ### Bottom Navigation Bar (BNB) * **Persistent Screens:** Home Dashboard, Quran Index, Azkar Index, Settings. * **Hidden On:** * Onboarding / Splash Screens. * Quran Reading View (to maximize focus). * Specific sub-flow modals (e.g., full-screen Qibla if triggered from outside the grid). * **Behavior:** Uses a "Soft Fade" cross-dissolve when switching between main tabs to maintain a spiritual, calm aesthetic. ### Global Back Action (RTL Context) * **Gesture:** Swipe from the **right edge** of the screen to the left. * **Transition:** `Slide Transition` (Outgoing screen slides right, Incoming screen slides in from left). * **Status Bar:** Color changes dynamically based on screen theme (Light/Dark). --- ## 2. State Management & Modal Triggers ### Modal Bottom Sheets Used for quick selections to keep the user in context: * **Calculation Method:** Triggered from Settings. Slides up from bottom. * **Location Permissions:** Triggered on first Qibla access. * **Notification Customization:** Deep-dive into specific prayer sound settings. ### Micro-interactions (Flutter Specifications) * **InkWell Ripple:** Used on all cards and buttons. Color: `primary_emerald_green.withOpacity(0.1)`. * **Haptics:** * `lightImpact`: Tab switching. * `mediumImpact`: Tasbeeh increment. * `heavyImpact`: Qibla alignment success. * **Loading States:** Custom shimmering effect (`Shimmer` package) on Dashboard cards during initial data fetch. --- **End of Document**
